About the studio

Y-Bridge Games is an independent game studio. We make games one careful piece at a time, and we finish what we start.

One bridge at a time

Every game is built in small steps: one playable piece, then the next, tested and tuned before we move on. It is slower than starting big, but each step stands on solid ground, and the game you play is the game we meant to make.

What we make

Our first game is Shardfall, a 2D isometric real-time strategy game about hero-led armies fighting across the ages for territory. It is in development now.
